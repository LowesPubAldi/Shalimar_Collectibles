Inventory

Browse card records across supported games. This shell is wired for search, filters, and results so we can connect live backend data in Version 1.

Search note: enter 3+ characters for names, or use short card IDs like P2 directly.

Search note: card IDs like P2, C56, ST1, or C156/176 also work here.

Game note: reserved for V1 guidance.

Set note: set-specific pricing context appears below when available.

Type note: reserved for V1 guidance.

Rarity note: options are game-specific and update based on selected game.

Edition note: use this for 1st vs unlimited print runs.

Finish note: quick isolate standard, foil, and rainbow cards.

Pricing note: load a set pricing file to mark priced cards and sort by value.

Gameplay note: YYH-only banned and limit 1 status can be filtered here.

Sort note: ordering applies across all loaded pages.

YYH inventory reads live API data and supports full card datasets; source credit remains with inviso (Mike) and the Yu Yu Hakusho TCG Database.
