Why This Exists

Shalimar Collectibles was made to preserve the cards and stories that shaped my love for collecting.

This project started as a place to organize what I could never find in one clean location: card details, set context, and real collector-focused tools for Yu Yu Hakusho and the games that grew alongside it. The goal is simple: build something useful first, then make it deeper with community feedback.

Why Shalimar Collectibles Was Built

I wanted a card resource that feels practical, honest, and personal. Most platforms are either too generic or too hard to navigate when you only need specific details. Shalimar Collectibles focuses on clear filters, reliable set information, and a user experience made for collectors who actually use this data every day.

This is a long-term build. Version 1 is about fundamentals: searchable inventory, set navigation, and dependable card records. Later versions will expand into community features, richer pricing systems, and collector workflows that are useful without being overwhelming.
